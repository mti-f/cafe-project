# ☕ Cafe Man

A modern cafe website built with HTML, CSS and JavaScript.

## ✨ Features

- Responsive design for mobile and desktop
- Product filtering and search
- Shopping cart system
- Online order form
- Dark mode
- Customer reviews section
- Contact form

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
